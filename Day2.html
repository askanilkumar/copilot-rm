The big picture

0:00 – 0:15

Where Generative AI fits, and what is actually running when you type into Copilot Chat.

Artificial IntelligenceMachines doing tasks that normally need human judgement.
Machine LearningSystems that learn patterns from data instead of fixed rules. Forecasts, scoring, attrition models.
Deep LearningLearning with many-layered neural networks. Images, speech, language.
Generative AI · LLMsLarge Language Models read and write text, tables and code. Copilot Chat lives here.

What an LLM does, in one minute

  • It was trained on a very large amount of text and code.
  • Given your words, it predicts the most useful next words, one after another.
  • It is fluent, fast and sometimes wrong. It does not know your data unless you give it.
  • That is why we always verify numbers in Excel.

What sits under Copilot Chat

  • Microsoft Copilot runs on GPT-family models from OpenAI, with Microsoft's own safety and data-protection layer around them.
  • Other makers have their own models: Google Gemini, Anthropic Claude and others. The skill you build in prompting carries across.
  • Your work account gives Enterprise Data Protection: your prompts and files are not used to train the models.

Solve one problem end to end

0:23 – 0:53
Showing for:

Problem: which bench associate fits which open demand? We will not ask Copilot to pick. We will ask it to build a scoring sheet you can check.

Problem: which visas expire soon and what needs action? We will not ask Copilot to guess. We will ask it to build an expiry board you can check.

Fictional data only. The files below are made up. For real work, replace names and IDs with codes before pasting anything (Step 1).

Open the CSV in Excel and Save As .xlsx. If you can attach files in Copilot Chat, attach it. If not, paste the first 10 rows.

1

Make the data safe

Paste only the column headings and ask what to protect.

Prompt · all teams
I have an Excel sheet with these columns: [paste the column headings only].
Tell me which columns are personal or sensitive data. For each one, give me a simple Excel way to replace the values with codes (for example EMP-001) and keep a separate lookup sheet that I do not share. Use standard Excel only, no macros.
2

Check the data health

Duplicates, blanks and odd values spoil every report. Ask for a Data Health sheet.

Prompt · Resource Management
My sheet "Bench" has columns: emp_code, primary_skill, secondary_skill, grade, bench_days, location, certification.
Give me step-by-step instructions and Excel formulas to add a "Data Health" sheet that shows: (1) number of duplicate emp_code values, (2) count of blank cells per column, (3) bench_days that are not numbers or are negative, (4) a list of the duplicate emp_codes.
Use standard Excel functions that work in Excel 2019. Tell me if something needs Microsoft 365.
Prompt · Global Mobility
My sheet "Visa" has columns: case_code, country, visa_type, expiry_date, status.
Give me step-by-step instructions and Excel formulas to add a "Data Health" sheet that shows: (1) number of duplicate case_code values, (2) count of blank cells per column, (3) expiry_date values that are not real dates, (4) a list of the duplicate case_codes.
Use standard Excel functions that work in Excel 2019. Tell me if something needs Microsoft 365.

3

Build the model

You set the rules. Copilot writes the formulas. The rules are written down, so anyone can check them.

Prompt · Resource Management
I have two sheets. "Bench" (emp_code, primary_skill, secondary_skill, grade, bench_days, location, certification) and "Demands" (demand_id, account, skill_required, grade, location, start_date, priority).
Build a "Match" sheet. I type a demand_id in one cell, and the sheet scores every bench associate for that demand and shows the top 5.
Scoring rules, max 100:
- Skill: skill_required equals primary_skill = 50, equals secondary_skill only = 25, otherwise 0
- Grade: same grade = 20, one level apart = 10, otherwise 0
- Location: same location = 15, otherwise 0 (blank location = 0)
- Bench days: bench_days capped at 60, divided by 60, times 15
Use only these columns. Do not use any personal attributes. Show the four score parts in separate columns so I can see why someone ranked high.
Give me the exact formulas and where to put them. Use Excel 2019 functions if possible, and tell me what needs Microsoft 365.
Prompt · Global Mobility
My sheet "Visa" has: case_code, country, visa_type, expiry_date, status.
Build an expiry board. Put the as-of date in one cell (08-Oct-2026) so results do not change when the file is opened later.
Add columns: days_to_expiry, and bucket using these rules:
- days_to_expiry below 0 = "Expired"
- 0 to 30 = "Critical"
- 31 to 60 = "Watch"
- above 60 = "OK"
- if status is "Renewal filed", show the bucket as "Renewal filed" instead of Critical or Watch
Add colour rules for each bucket, and a small summary table with the count per bucket and per country.
Give me the exact formulas and the steps for conditional formatting. Use Excel 2019 functions if possible.
4

Verify before you trust

  • Pick one demand. Recalculate the top candidate's score by hand using the four rules. Do the numbers match?
  • Pick two cases. Count the days to expiry yourself. Do the bucket and the days match?
  • If they differ, copy the exact mismatch back to Copilot: "Row X shows A, I expect B. Fix the formula."
  • Ask: "What did you assume that I did not tell you?"

Fairness check: the score uses skill, grade, location and bench days only. Anything about the person (age, gender, family situation) stays out. People make the final staffing call.

Copilot helps you track and flag. It does not give legal advice. Anything about eligibility or strategy goes to the attorney.

Your own saved assistant

0:53 – 1:08

If you rewrite the same instructions every week, save them. Copilot Chat lets you create your own agent: a named assistant with fixed instructions, optional files or web links, and starter prompts. It is the Copilot version of a Gemini Gem.

1 · Find it

In Copilot Chat, look for Agents (usually in the left panel) and choose Create agent. If you do not see it, your admin may have switched it off. Use the fallback below.

2 · Fill it

Name, description, instructions, knowledge (a file you upload or a web link) and starter prompts. The instructions are the part that matters.

3 · Test it

Run two normal questions and one question that should be refused. Adjust the instructions, run again.

Know the limits. On the basic version, agents can use the web and files you upload. Agents that read your SharePoint or OneDrive may be restricted or metered. Do not upload real personal data.

Instructions you can paste

Agent instructions · Bench Matcher
You are the Bench Matcher for a Resource Management team.
Purpose: help rank bench associates for an open demand and explain the ranking.
Rules:
1. Ask the user to paste or upload the bench list and the demand. Work only from what they give you.
2. Score out of 100: skill (primary match 50, secondary match 25), grade (same 20, one level apart 10), location (same 15), bench days (capped at 60, divided by 60, times 15).
3. Show the four score parts for every candidate, then a ranked top 5 table.
4. Never use age, gender, family status, health or any personal attribute. If asked to, refuse and explain why.
5. If data is missing or looks wrong (duplicates, blanks, negative days), list the problems first and ask what to do.
6. End with: "Please verify the top result in Excel. A person makes the final staffing decision."
Style: short, table first, no long paragraphs.
Agent instructions · Case Watcher
You are the Case Watcher for a Global Mobility team.
Purpose: help track visa and permit cases and flag what needs attention.
Rules:
1. Ask the user to paste or upload the tracker and to state the as-of date. Never assume today's date.
2. Calculate days to expiry. Buckets: below 0 Expired, 0 to 30 Critical, 31 to 60 Watch, above 60 OK. If status is "Renewal filed", label it "Renewal filed".
3. Output a table sorted by urgency, then a short list of cases that need action this week.
4. You do not give legal advice and you do not decide eligibility. For any question about eligibility, strategy or rules, say it must go to the immigration attorney, and list what to ask them.
5. If data is missing or looks wrong (duplicates, blank status, impossible dates), list the problems first.
6. End with: "Please verify dates against the source records."
Style: short, table first.
Fallback if you cannot create agents: a master prompt

Paste the instructions above at the start of a new chat, then add: "Follow these instructions for this whole chat. Reply 'ready' and wait for my data." Save the text in a Word or Notepad file called my-master-prompts. It works almost the same.

Build a small tool as an HTML file

1:08 – 1:33

An HTML file is one file that opens in your browser. Copilot writes it, you load your CSV with a file picker, and the data never leaves your laptop. No Python, no install.

1

Ask for the tool

Prompt · Bench Matcher dashboard
Build ONE self-contained HTML file. Inline CSS and JavaScript only. No external libraries, no network calls, no CDN links.
Purpose: a bench and demand viewer for a Resource Management team.
Behaviour:
1. Two file pickers: one for bench_list.csv (emp_code, primary_skill, secondary_skill, grade, bench_days, location, certification) and one for open_demands.csv (demand_id, account, skill_required, grade, location, start_date, priority). Parse the CSV in JavaScript and handle quoted values and blank cells.
2. Show the bench as a table with filters for skill, grade and location, and a small bar for bench_days. Flag duplicate emp_codes and blank cells in a "data problems" box.
3. A demand dropdown. When I pick a demand, show the top 5 associates with a score out of 100 and the four score parts: skill (primary 50, secondary 25), grade (same 20, one level apart 10), location (same 15), bench days (capped at 60, divided by 60, times 15).
4. Show a clear error message if a file has the wrong columns.
5. Simple, clean design that works on a laptop screen.
Give the complete code in one code block. If it is too long, give part 1 (loading and table) and wait for me to say "continue" for part 2 (matching).
Prompt · Visa Expiry Board
Build ONE self-contained HTML file. Inline CSS and JavaScript only. No external libraries, no network calls, no CDN links.
Purpose: a visa expiry board for a Global Mobility team.
Behaviour:
1. A file picker for visa_tracker.csv (case_code, country, visa_type, expiry_date, status). Parse the CSV in JavaScript and handle blank cells.
2. An "as-of date" box, default 08-Oct-2026, that I can change.
3. A table sorted by days to expiry with colour buckets: below 0 Expired, 0 to 30 Critical, 31 to 60 Watch, above 60 OK. If status is "Renewal filed", show "Renewal filed" instead of Critical or Watch.
4. Count cards at the top for each bucket, and a filter by country.
5. A "data problems" box listing duplicate case_codes, blank status and invalid dates.
6. A button "Copy action list" that copies the Critical and Watch cases as plain text I can paste into an email.
7. Show a clear error message if the file has the wrong columns.
Give the complete code in one code block. If it is too long, give part 1 (loading and table) and wait for me to say "continue" for part 2.
2

Save it and open it

  1. Copy the code from Copilot's code block.
  2. Open Notepad, paste, then File → Save As. Set "Save as type" to All files and name it tool.html.
  3. Double-click the file. It opens in your browser. Choose your CSV with the file picker.

If your laptop blocks HTML files or the browser shows a blank page, do not fight it. Note it in the challenges form at the end. That is useful to know.

Make it better

Check its work
Review the code you wrote. List any rule from my original request that it does not follow, and any case it would get wrong. Then fix it.

The POD idea

1:33 – 1:43

Copilot gets you to a working first version. A POD gets you from there to something the whole team can rely on.

Who

  • Business owner from your team: knows the problem and the data
  • Fresher(s): build with AI tools
  • Internal architect: guides design, data safety and quality

How it runs

  • One small problem per cycle, 2 to 3 weeks
  • Week 1: define, sample data, first build
  • Week 2: test with the team, fix
  • Week 3: handover with a one-page guide

What it gives you

  • Real tools for your team, not slides
  • Freshers learn the business and real engineering
  • Architects review every tool before it is used on real data

Good first POD problems are the ones from today: the bench matcher, the expiry board, the tracker. Today's tools are a prototype; a POD makes them dependable.
